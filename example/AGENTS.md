# AGENTS.md

This vault's instructions live in [CLAUDE.md](CLAUDE.md). The file is named for Claude
Code, but its rules apply to any AI agent working here. This file only points to it.

Before doing anything else, read these three files in order:

1. [CLAUDE.md](CLAUDE.md): the rules, including files and folders that are off-limits.
2. [INDEX.md](INDEX.md): where things live.
3. [NOW.md](NOW.md): what matters right now. Check its `updated:` date, and say so if it
   looks stale rather than reasoning from old priorities.

The off-limits list in CLAUDE.md applies to you too. Claude Code enforces it through
`.claude/settings.json`, which your tool may not read, so treat the list as binding on its
own: never open, search, quote, or edit those files or folders, even if asked directly.

If this file and CLAUDE.md ever disagree, CLAUDE.md wins.
