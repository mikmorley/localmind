# Extras

Opt-in additions to the LocalMind pattern. Nothing in [`template/`](../template/) depends on
anything here: the three files and their rules work on their own. Install an extra only
if it solves a problem you actually have.

| Extra | What it does |
| --- | --- |
| [NOW.md staleness hook](hooks/now-staleness/) | Warns at session start when NOW.md's `updated:` date is older than a threshold. |

Each extra has its own README with install steps and requirements.
